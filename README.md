# Food Nutrition Analyzer using Agentic AI

A simple AI-based application that helps users understand the nutrition in their food. Users can enter their meal or upload a food image, and the system analyzes it to show calories, protein, carbs, fats, and other nutrients.

Different AI agents work together to identify food, analyze nutrition, and give personalized recommendations.

### Features

* Food image/text analysis
* Nutrition calculation
* Daily meal tracking
* AI-based recommendations
* Nutrition reports
